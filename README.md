# Faz Pizza 🍕

Sitio web elegante y responsive para **Faz Pizza**, una pizzería artesanal que celebra la masa fermentada lentamente, los ingredientes frescos y el sabor del fuego.

## ✨ Sobre el proyecto

**Faz Pizza** presenta una experiencia visual inspirada en la cocina italiana: tipografía con carácter, tonos cálidos, fotografía gastronómica y una navegación sencilla.

La página incluye:

- Hero principal con identidad de marca.
- Menú destacado con pizzas, descripciones y precios.
- Sección de filosofía y elaboración artesanal.
- Navegación adaptable para escritorio y dispositivos móviles.
- Animaciones suaves al hacer scroll.
- Diseño completamente responsive.

## 🛠️ Tecnologías

- **HTML5** para la estructura semántica.
- **CSS3** para el diseño, responsive layout y animaciones.
- **JavaScript** para el menú móvil y las revelaciones al desplazarse.
- **SVG** para el logotipo.

No requiere compilación ni instalación de dependencias.

## 🚀 Cómo verlo

1. Abre el archivo `index.html` directamente desde tu navegador.

También puedes usar una extensión como **Live Server** en Visual Studio Code:

1. Instala la extensión Live Server.
2. Haz clic derecho sobre `index.html`.
3. Selecciona **Open with Live Server**.

## 📁 Archivos principales

```text
pizzeria/
├── index.html       # Contenido y estructura de la página
├── styles.css       # Estilos y diseño responsive
├── script.js        # Menú móvil y animaciones
├── pizza.svg        # Marca y favicon
└── README.md        # Documentación del proyecto
```

## 🎨 Personalización

Los colores, tipografías y variables principales están definidos al inicio de `styles.css`.

```css
:root {
  --paper: #f7f3eb;
  --ink: #26241f;
  --red: #c83d27;
  --olive: #65704a;
}
```

Para modificar el contenido, las pizzas o los datos de contacto, edita las secciones correspondientes en `index.html`.
